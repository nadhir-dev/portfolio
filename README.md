# Nadhir Bendraou — Portfolio

Personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Development

```bash
bun install
bun dev
```

Open `http://localhost:3000`.

## Scripts

```bash
bun dev
bun run build
bun start
bun run lint
```

## Environment

Create `.env` locally:

```bash
RESEND_API_KEY=
CONTACT_TO_EMAIL=nadhir.code@gmail.com
CONTACT_FROM_EMAIL="Portfolio <contact@portfolio.nadhirbendraou.com>"
NEXT_PUBLIC_CONTACT_EMAIL=nadhir.code@gmail.com
NEXT_PUBLIC_GITHUB_URL=https://github.com/nadhir-dev
NEXT_PUBLIC_INSTAGRAM_URL=https://www.instagram.com/nadhir.dev
NEXT_PUBLIC_LINKEDIN_URL=https://www.linkedin.com/in/nadhirdev
NEXT_PUBLIC_TIKTOK_URL=https://www.tiktok.com/@0xnadhir
```

The newsletter form stays disabled until `newsletterUrl` is set in `data/site.ts`.
The resume link stays disabled until `resumeUrl` is set in `data/site.ts`.
